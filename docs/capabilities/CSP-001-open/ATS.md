# Acceptance Test Specification

## Acceptance Criteria

- [ ] `vestara open .` completes without crashing
- [ ] `.vestara/` directory created with workspace.json
- [ ] Workspace identity established (git-aware, non-git fallback)
- [ ] Repository analysis produces language, framework, entry points, risks
- [ ] Health score computed (0-10)
- [ ] Knowledge index built and persisted
- [ ] Workspace session created with engines
- [ ] REPL prompt changes to `{repo-name} >`
- [ ] No architectural contracts violated
- [ ] Offline operation supported
