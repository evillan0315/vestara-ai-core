## Build Order (executable architecture)

```text
shared → configuration → logger → metrics → event-bus → service-registry →
health → permission → stream →
provider-runtime → providers/opencode →
context → memory → cognitive → knowledge → reasoning →
action → state-runtime → conversation →
audio → stt → tts →
conversation-runtime →
activity-log →
tools/filesystem →
workspace →
events-server → os-controller →
kernel

Then apps/api and apps/cli (in parallel).
```

This order is enforced by `build-order.sh`. A circular dependency breaks the build.
