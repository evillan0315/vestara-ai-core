# @vestara/workspace

Workspace runtime pipeline and product services.

## Usage

Import via workspace reference:

```
pnpm --filter @vestara/workspace build
```

## Dependencies

`@vestara/context @vestara/conversation @vestara/event-bus @vestara/knowledge @vestara/logger @vestara/memory @vestara/reasoning @vestara/shared @vestara/stream `

See [docs/](../docs/) for capability specifications and architecture.
