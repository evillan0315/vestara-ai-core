# @vestara/workflow-orchestrator

Multi-agent workflow orchestration core — project/plan/task state machines, task graph, retry policy, stores, and the WorkflowOrchestrator (ADR-004 / ADR-118).

## Usage

Import via workspace reference:

```
pnpm --filter @vestara/workflow-orchestrator build
```
