# @vestara/browser-runtime

Kernel-level browser runtime service — lifecycle-managed browser sessions with event emission and evidence collection.

## Usage

Import via workspace reference:

```
pnpm --filter @vestara/browser-runtime build
```

## Dependencies

`@vestara/tools-browser @vestara/event-bus @vestara/evidence @vestara/shared`

See [docs/](../docs/) for capability specifications and architecture.
