# @vestara/cli

CLI entry point REPL and demo commands.

## Usage

Import via workspace reference:

```
pnpm --filter @vestara/cli build
```

## Dependencies

`@vestara/kernel @vestara/shared @vestara/state-runtime @vestara/context @vestara/conversation @vestara/provider-runtime @vestara/provider-opencode @vestara/workspace @vestara/events-server `

See [docs/](../docs/) for capability specifications and architecture.
