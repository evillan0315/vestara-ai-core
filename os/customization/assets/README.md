# Vestara Branding Assets

Place reviewed, redistributable assets here before wiring them into the image
builder:

- `vestara-mark.svg` — vector logo source
- `vestara-mark.png` — bootloader/splash raster export
- `vestara-wallpaper.png` — login or desktop background
- `fonts/` — fonts with compatible redistribution licenses
- `colors.json` — canonical color tokens

Keep source assets separate from generated exports and record licenses for
anything that is not authored by Vestara.
